# Elsie.Sample.Full

Kitchen sink — auth, CORS, rate limit, health, CSRF, static, views. Keep Views/ and wwwroot/. Demo: ada / pass; GET /csrf first.

Uses **NuGet** packages only — copy this folder and run (no monorepo required):

```bash
dotnet run
```

Requires .NET 8 SDK. Package versions are in `Elsie.Sample.Full.csproj`.
